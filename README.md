# MIT 6.006: Introduction to Algorithms ⚡

This repository contains my algorithmic implementations and problem set solutions for **MIT 6.006**, the definitive algorithms and data structures course.

This curriculum represents the core of my technical problem-solving foundation. The focus is on the rigorous mathematical analysis of algorithms, proving computational correctness, and engineering solutions that scale efficiently under massive data loads.

## 🧠 Core Concepts & Implementations
- **Graph Traversal & Shortest Paths:** Mastery of Breadth-First Search (BFS) and Depth-First Search (DFS) topological patterns, alongside Dijkstra's and Bellman-Ford algorithms for optimal routing.
- **Sorting & Trees:** Implementation of Heap Sort, Merge Sort, and Radix Sort, alongside balancing Binary Search Trees (AVL trees) to maintain strictly O(log n) operations.
- **Dynamic Programming:** Breaking down complex combinatorial problems into overlapping subproblems utilizing memoization and bottom-up tabulation to achieve polynomial time complexities.
- **Hashing & Dictionaries:** Engineering hash functions, resolving collisions via chaining and open addressing, and optimizing average-case O(1) lookups.
- **Asymptotic Complexity:** Rigorous runtime analysis using Big O, Big Omega, and Big Theta notations to prove theoretical efficiency bounds.

## 📂 Repository Structure
* **/algorithms:** Core template implementations of fundamental algorithms (including BFS/DFS state-tracking templates, sorting routines, and DP paradigms).
* **/psets:** Solutions to MIT's rigorous analytical and programming assignments, strictly adhering to target runtime complexities.

* **Language:** Python 3
